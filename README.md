# Credits EX

Original animation ([Watch video](https://youtu.be/o3cKQzrtFgQ?si=Dbo2Luq85-IUR6FJ)) designed and programmed in Python by [plaaosert](https://github.com/plaaosert), and remade in Rust by me (KnowHT).

Music: [Credits EX](https://soundcloud.com/frums/credits-ex) by [Frums](https://www.frums.xyz/)

## How To Run

By the way, due to copyright concerns, the original music is not included in this package. You'll need to obtain a copy of the music yourself. Sorry about that.

1. Get a copy of `Credits EX`, convert it to `credits-ex.wav`, and drop it in the `./audio/` folder. 
2. Make sure you have `Rust` and `Cargo` properly installed.
3. Run `build.ps1` or `build.cmd`.
4. Open the `./dist/credits-ex/` folder and double-click the `credits-ex.exe`.
5. Enjoy the animation!

## Any Other Word?

- This project currently supports `Windows` (Tested on `Rust 1.96`, `Windows 11`) only. `macOS` and `Linux` have not been tested and may not work properly.
- If you want an experience closer to the original animation, try using `Consolas` as your terminal font.
- Feel free to raise an issue for anything.
